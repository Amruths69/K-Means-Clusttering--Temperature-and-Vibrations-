# K-Means Clustering — Temperature & Vibration

A beginner-friendly machine learning project to understand **K-Means Clustering** using Python and Scikit-learn.

## 📌 About the Project

In this project, I learned and implemented **K-Means Clustering** using a small dataset containing two features:

- **Temperature**
- **Vibration**

The goal was to group similar data points into **3 different clusters** based on these two features.

This project was created while learning clustering concepts through **Kaggle** and practicing them using Python.

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- K-Means Clustering

## 📊 Dataset

The dataset contains two numerical features:

| Feature | Description |
|---|---|
| Temperature | Temperature value |
| Vibration | Vibration value |

The data was created directly as a Pandas DataFrame for learning and experimentation.

## ⚙️ What I Did

### 1. Imported the required libraries

Used:

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.cluster import KMeans
```

### 2. Created the dataset

Created a Pandas DataFrame containing Temperature and Vibration values.

### 3. Visualized the data

Created a scatter plot to understand the relationship between Temperature and Vibration.

```python
plt.scatter(x="Temp", y="Vib", data=df)
```

### 4. Prepared the data

Selected the two features for clustering:

```python
x = df[["Temp", "Vib"]]
```

### 5. Applied K-Means Clustering

Created a K-Means model with **3 clusters**:

```python
model = KMeans(n_clusters=3, random_state=42)
model.fit(x)
```

### 6. Added cluster labels

Used the cluster labels generated by the model to create a new column:

```python
df["Cluster"] = model.labels_
```

### 7. Visualized the clusters

Used Seaborn to display the three clusters with different colors.

```python
sns.scatterplot(
    x="Temp",
    y="Vib",
    data=df,
    hue="Cluster"
)
```

### 8. Visualized the centroids

Retrieved the cluster centers using:

```python
centroids = model.cluster_centers_
```

Then plotted them separately on the scatter plot.

The centroids represent the **center point of each cluster** calculated by K-Means.
